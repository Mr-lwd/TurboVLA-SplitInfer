# Evaluation data catalog

`catalog.json` preserves the complete source catalog. `latest.json` and `summary.csv` publish only the current comparison selected by `featured_group` for the README and website. Exported data retains configuration, per-task results and source SHA-256 checksums.

See the [benchmark page](../../docs-site/guide/benchmark-results.md) and [methodology/update guide](../../docs-site/guide/benchmark-data.md). Raw evaluation records and videos remain under `outputs/`; model weights are managed separately.

Display notes are localized to English during publication without altering raw source records or numeric metrics.
